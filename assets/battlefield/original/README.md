# 헤네시스 새 도트 원화

2026-10-18 사용자 결정: WZ 추출 맵 소품을 사용한 시범을 교체한다. 헤네시스의 밝은 버섯 마을 분위기를 참고해 바닥과 건물/식생/시설을 새로 제작한다. 스타듀밸리처럼 넓은 탑뷰 마을 구조를 사용하되 사방 전투 통로를 확보한다.

생성 방식: 내장 image_gen. 원본 게임 그림/추출 PNG는 생성 입력으로 사용하지 않는다. 생성 결과 원본 PNG를 이 폴더에 보존하며 게임 로더가 atlas 셀을 읽는다. 생성 프롬프트와 원본 파일 해시, 실제 검사 기록은 제작 완료 시 provenance.json에 기록한다. 기존 캐릭터/몬스터/전투/HUD 리소스와 다른 지역의 맵 리소스 교체는 이번 범위가 아니다.
